# Политика безопасности

Этот репозиторий — образовательный практикум (сценарий, тексты, конфиг
для локального запуска через `opencode`). В нём нет серверной части,
пользовательских данных или продакшен-инфраструктуры — но конфигурация
`.opencode/` и скрипты могут содержать баги, которые стоит знать нам.

## Как сообщить об уязвимости

Не создавайте публичный issue для уязвимостей. Вместо этого используйте
приватный отчёт через GitHub:

**Security → Report a vulnerability** на странице репозитория
(GitHub Private Vulnerability Reporting).

Опишите:

- в чём проблема и как её воспроизвести;
- потенциальное воздействие (например, выполнение произвольных команд
  при запуске практикума);
- версию `opencode` и окружение.

Мы рассмотрим сообщение и ответим в разумные сроки. Обычные баги без
угрозы безопасности (опечатки, сюжетные нестыковки, проблемы с
прогресс-файлом) заводите как обычный issue — см. [CONTRIBUTING.md](CONTRIBUTING.md).
