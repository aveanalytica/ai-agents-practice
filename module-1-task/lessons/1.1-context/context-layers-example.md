# Один и тот же запрос — без контекста и с четырьмя слоями

## Запрос А — без контекста

> Напиши анонс новой функции сервиса знакомств «Дуэт».

**Что модели придётся додумать самой — и она это сделает молча:**

- **Какая функция?** Придумает какую-нибудь — «умные подсказки», «AI-помощник», что угодно.
- **Для кого анонс?** Решит за тебя: то ли для новых пользователей, то ли для прессы, то ли для действующих.
- **Где опубликуют?** Выберет наугад — пост в соцсетях? письмо? пуш в приложении?
- **Что нельзя обещать?** Не знает про твои ограничения — наобещает продление подписки и сравнит с конкурентами по именам.

Результат — гладкий текст, который невозможно использовать: красиво про функцию, которой нет, для аудитории, которой не существует.

## Запрос Б — те же четыре слоя заполнены

> **Цель:** показать ценность функции — вызвать приток новых пользователей и волну пробных премиум-периодов у текущих.
>
> **Доменные знания:** продукт — сервис знакомств «Дуэт»; функция — ИИ-помощник для начала беседы (ИИ генерирует первое универсальное сообщение в чате, после первой генерации пользователь получает премиум-подписку на 7 дней). На базовом (бесплатном) тарифе, доступна с сегодняшнего дня.
>
> **Аудитория:** действующие и потенциальные пользователи приложения. Канал — пост в соцсетях, тон расслабленный и весёлый.
>
> **Ограничения:** не обещать продление премиум-подписки, не сравнивать с конкурентами по именам.

Результат — анонс, который можно отправить: про реальную функцию, нужным людям, в нужном тоне, без обещаний, за которые потом краснеть.
