# Практикум AVE Analytica по работе с ИИ-агентами

Интерактивный практикум из шести модулей, который проходится прямо в терминале:
открываешь папку модуля в [opencode](https://opencode.ai) — и агент-преподаватель
ведёт тебя по занятиям сам, шаг за шагом.

## Как начать

```bash
git clone https://github.com/aveanalytica/ai-agents-practice.git
cd ai-agents-practice/module-1-task
opencode
```

Напиши любое сообщение — занятие начнётся автоматически.

## Модули

| Папка | Модуль | О чём |
|---|---|---|
| `module-1-task` | Модуль 1 · Постановка задачи | как ставить задачи модели, чтобы получать полезный результат |
| `module-2-check` | Модуль 2 · Проверка результата | как не принять убедительную ошибку за нормальную работу |
| `module-3-loop` | Модуль 3 · Путь к рабочему результату | цикл доводки, материал для модели, инструменты |
| `module-4-agents` | Модуль 4 · Работа с агентом | ТЗ агенту, границы, точки контроля |
| `module-5-assistant` | Модуль 5 · Персональный ассистент | свои рабочие сценарии, проект и скиллы |
| `module-6-scale` | Модуль 6 · Масштаб: команда агентов | параллельные агенты, оркестрация, сабагенты |

Новичок — начни с Модуля 1. Модули 4–6 продвинутые, проходи их после первых трёх.

## Как это устроено

- Каждый модуль — самостоятельная папка со своим `AGENTS.md` (роль преподавателя),
  скриптами занятий в `lessons/` и командами запуска в `.opencode/command/`
  (`/start-1-1`, `/start-2-3` и т.д. — можно начать с конкретного занятия).
- Занятия интерактивные: преподаватель спрашивает, ждёт твоего ответа, разбирает
  его и ведёт дальше по скрипту.
- Практика идёт на встроенных демо-данных — ничего подключать и никуда
  не нужен доступ.
- Шпаргалки модулей лежат в `cheatsheets/` (PDF).
