# Практикум AVE Analytica по работе с ИИ-агентами

Интерактивный практикум из трёх модулей, который проходится прямо в терминале:
открываешь папку модуля в [opencode](https://opencode.ai) — и агент-преподаватель
ведёт тебя по занятиям сам, шаг за шагом.

## Как начать

```bash
git clone https://github.com/aveanalytica/ai-agents-practice.git
cd ai-agents-practice/module-1-model
opencode
```

Напиши любое сообщение — занятие начнётся автоматически.

**В следующий раз** просто открывай `opencode` из корневой папки `ai-agents-practice` (`cd ai-agents-practice && opencode`) — преподаватель сам напомнит, на каком занятии вы остановились в каждом модуле, и подскажет команду для продолжения. Клонировать репозиторий заново не нужно — прогресс хранится локально в вашей копии репозитория.

## Модули

| Папка | Модуль | О чём |
|---|---|---|
| `module-1-model` | Модуль 1 · Дисциплина работы с моделью | постановка задачи + проверка результата |
| `module-2-agent` | Модуль 2 · Путь к результату с агентом | цикл доводки, материал для модели, работа с агентом |
| `module-3-scale` | Модуль 3 · Масштаб: ассистент и команда агентов | личный проект со скиллами, параллельные агенты, оркестрация, сабагенты |

Новичок — начни с Модуля 1. Модуль 3 продвинутый, проходи его после первых двух.

## Как это устроено

- Каждый модуль — самостоятельная папка со своим `AGENTS.md` (роль преподавателя),
  скриптами занятий в `lessons/` и командами запуска в `.opencode/command/`
  (`/start-1-1`, `/start-2-3` и т.д. — можно начать с конкретного занятия).
- Занятия интерактивные: преподаватель спрашивает, ждёт твоего ответа, разбирает
  его и ведёт дальше по скрипту.
- Практика идёт на встроенных демо-данных — ничего подключать и никуда
  не нужен доступ.
- Шпаргалки модулей лежат в `cheatsheets/` (PDF).
- Каждый модуль сам сохраняет прогресс в `.progress/` (локально, не в git) —
  при следующем запуске преподаватель продолжит с занятия, на котором вы
  остановились.
