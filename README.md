# Практикум «Штаб РОК»

[![License: CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey.svg)](LICENSE)

Интерактивный практикум AVE Analytica по работе с ИИ-агентами — в формате
антикризисной истории. Ты — новый ведущий аналитик ООО «Рога и Копыта»: квартал
провален, отделы винят друг друга, а через 14 дней совет директоров ждёт твой доклад.
Агент-куратор ведёт тебя по 16 миссиям прямо в терминале: открываешь репозиторий
в [opencode](https://opencode.ai) — и расследование начинается.

## Как начать

```bash
git clone https://github.com/aveanalytica/ai-agents-practice.git
cd ai-agents-practice
opencode
```

Напиши любое сообщение — куратор поздоровается и начнёт миссию 1.1.

**Продолжить в другой день:** снова `cd ai-agents-practice && opencode` — куратор
сам напомнит, на какой миссии вы остановились. Клонировать заново не нужно:
прогресс хранится локально в твоей копии (`.progress/`, в git не попадает).

## Как это устроено

- Один запуск — всегда из корня репозитория. Куратор читает роль из `AGENTS.md`
  и ведёт миссии по скриптам из `missions/`.
- Миссия — короткий рабочий эпизод, ориентировочно 7–12 минут (темп твой, это
  не таймер): куратор показывает ситуацию, ты ставишь задачу агенту, он её
  делает, ты проверяешь или исправляешь результат. 2–3 содержательные остановки
  на миссию, подсказки и заготовки запросов — сразу под рукой.
- Читать документы целиком не нужно: куратор читает файлы `company/` сам
  и показывает нужные выдержки с источником. Захочешь посмотреть документ
  целиком — попроси, он откроется.
- С первой миссии ты собираешь собственный **рабочий штаб** в
  `rok-crisis-room/`: дневник, реестр доказательств, гипотезы, скиллы
  и сабагенты. К финалу агент собирает из штаба короткий доклад — ты
  проверяешь три факта и одну оговорку.
- Начать конкретную миссию можно командой `/start-2-3` или фразой «давай
  миссию 2.3». После создания своего скилла или субагента куратор попросит
  перезапустить opencode — вернуться на место поможет та же команда
  `/start-N-M`, прогресс при этом не слетает.

## Четыре акта

| Акт | Миссии | Что происходит |
|---|---|---|
| 1 · Цифры не сходятся | 1.1–1.4 | Первый день, контекст, запрос под результат, первая пойманная ошибка модели |
| 2 · Три версии | 2.1–2.4 | Отделы обвиняют друг друга: гипотезы, доводка анализа, порча смысла, цена ошибки |
| 3 · Штаб | 3.1–3.4 | Превращаем рутину в систему: ТЗ агенту, скилл, параллельные агенты — и данные, которые ломают версию |
| 4 · Совет директоров | 4.1–4.4 | Команда сабагентов, оркестрация, человек в контуре и финальный доклад |

Миссии идут по нарастающей и связаны одним сюжетом: выводы одной миссии —
входные данные следующей. Проходи по 1–2 миссии за подход, прогресс
сохраняется сам после каждой завершённой миссии.

## Связь с курсом

Практикум — бонусный модуль курса «CLI-агенты» кабинета AVE Analytica School.
Теория (AGENTS.md, permissions, скиллы, сабагенты, оркестрация) — в модуле 3 курса,
стартовый урок с инструкцией — в модуле 4.
