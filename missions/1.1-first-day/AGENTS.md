# Миссия 1.1 · Первый день

Приём: поставить агенту задачу по брифу и проверить источник.
Результат: `rok-crisis-room/README.md`, `rok-crisis-room/diary.md`.

Ориентир: 7–12 минут, темп выбирает студент.

## Скрипт

### 1. Поручение директору не пересказываем, агенту ставим задачу

Скажи: «Ты в штабе РОК. Через 14 дней совет директоров, Q3 ниже плана. Геннадий Петрович ждёт объяснение с цифрами и план Q4. Сегодня заведём штаб, не будем придумывать причины. Я прочитаю служебку, а ты задашь результат работы.»

Action: прочитай полностью `company/inbox/director-brief.md`. Покажи только три короткие выдержки: план/факт и два пункта задачи, с путём и номерами строк. Не выводи документ целиком. Дай заготовку:

> Прочитай `company/inbox/director-brief.md`. Создай `rok-crisis-room/README.md`: цель штаба, [какие два результата ждёт директор], срок и ссылка на источник. Причины пока не называй. `company/` не меняй.

Скажи: «Замени скобки конкретными результатами и отправь задание. Подсказка уже в двух пунктах служебки: объяснение Q3 с цифрами и план Q4. Можно взять их прямо оттуда.»

Check: дождись задания с двумя результатами, а не ответа «ок». Не требуй пересказа подсказки своими словами.

Action: выполни задание: создай README с целью, двумя результатами, сроком и источником. При повторе обнови только вводный блок миссии 1.1, сохрани остальные разделы. Перечитай файл и покажи три строки: результаты и срок, рядом с выдержками служебки.

### 2. Принимаем сделанное по источнику

Скажи: «Сверь одну строку README со служебкой. Напиши, например: “В README указан срок …, в источнике строка …; совпадает, оставь”. Если не совпадает, дай команду исправить конкретную строку. Так мы проверяем сделанное, а не только обещание агента.»

Action: держи перед студентом короткую пару «запись штаба / источник». По просьбе покажи ещё одну нужную строку, не весь файл.

Check: студент сверил конкретный результат или срок с источником и дал решение: оставить проверенную строку либо исправить её.

Action: внеси указанную правку, если она нужна, и перечитай изменённый блок. Создай `rok-crisis-room/diary.md`, только если его ещё нет; существующие записи не трогай. Строку об этой миссии добавит общее завершение.
