# Миссия 1.2 · Четыре слоя контекста

Приём: дать агенту контекст через файл и выбрать рабочее ограничение.
Результат: `rok-crisis-room/context.md`.

Ориентир: 7–12 минут, без таймера.

## Скрипт

### 1. Контекст уже собран, добавь границу

Скажи: «Чтобы агент работал с РОК, ему нужны цель, сведения о компании, аудитория и ограничения. Перепечатывать досье не надо. Я подготовлю четыре поля, ты решишь, где остановить анализ.»

Action: прочитай полностью `company/handbook.md` и `company/inbox/director-brief.md`, затем README штаба. Покажи не документы, а короткую таблицу с путями источников:

| Поле | Заготовка | Источник |
|---|---|---|
| Цель | Объяснение Q3 с цифрами и план Q4 к совету через 14 дней от брифа | company/inbox/director-brief.md |
| Предметная область | Оптовые поставки фермерам; около 120 клиентов; «Заря» даёт 28% выручки Q2 | company/handbook.md |
| Аудитория | Директор, инвестор, аудитор | company/inbox/director-brief.md |
| Ограничения | Только факты из company/ со ссылками; версии отделов не считать доказанными | Правило работы штаба |

Скажи: «Хочешь другое ограничение — замени одну фразу, например на "не назначать виновных". Напиши мне (можно просто скопировать):

"Сохрани эти четыре поля в rok-crisis-room/context.md. Добавь ограничение: пока не давать рекомендации Q4. Прочитай сохранённый контекст и предложи один следующий шаг расследования, соблюдая его."»

Check: студент отправил задание с конкретным ограничением, влияющим на результат.

Action: выполни команду: запиши четыре поля и выбранное ограничение, перечитай файл. При повторе обновляй только эти поля, сохраняя поздние дополнения и уточнения. Предложи один шаг со ссылкой на подходящий источник; не объявляй причины доказанными.

### 2. Контекст должен менять ответ

Скажи: «Проверь, что мой шаг соблюдает твоё ограничение. Если нет — напиши правку, например: "Убери рекомендации, оставь только проверку". Напиши мне, например:

"Соблюдает: это шаг проверки фактов, а не план Q4 — принимаю."»

Action: покажи выбранное ограничение из сохранённого файла и свой следующий шаг, всего две короткие строки с путём к контексту.

Check: студент сопоставил действие с выбранной границей; одного «подходит» недостаточно, нужна конкретная формулировка или команда исправления.

Action: выполни нужную правку ответа или ограничения, если студент уточнил его; перечитай изменённое поле. Не добавляй в контекст непроверенные причины как факты.

## Завершение

Action: выполни общее завершение миссии 1.2 из `.opencode/SCRIPT_INSTRUCTIONS.md`.

- В context.md есть четыре поля и выбранное студентом ограничение.
- Агент использовал сохранённый контекст, студент проверил соблюдение границы.
