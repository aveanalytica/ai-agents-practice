# Миссия 1.4 · Первое несовпадение

Боевая миссия: прогон запроса по реальным цифрам, уверенная ошибка модели,
чек-лист оценки результата и первый реестр доказательств.

## Цель миссии

Студент ловит правдоподобную неточность, оценивает результат по чек-листу
и заводит `evidence/ledger.md` — главный артефакт расследования.

## Скрипт

### 1. Прогон

Action: покажи студенту содержимое `company/data/sales-q3.md` целиком.

Скажи: «Прогоняем. Собери полный запрос: контекст из `context.md` + запрос
из `briefs/request-q3.md` — и пришли мне. Я отвечу как модель.»

Check: студент присылает полный запрос.

**Ответь как модель — красиво и с одной порчей смысла.** Наблюдения (все верные
по файлу): план/факт по месяцам, углубление провала (−7/−18/−29%), «Хуторок»
и «Луговое» −68/−67%, сегмент «остальные» −21%. **Порча:** подай это как
«равномерное падение по клиентской базе из-за общего ухудшения спроса» и
**не упомяни рост «Зари» +9%** — сгладь его фразой «ключевые клиенты
поддержали выручку». Гипотезы: «сезонный спад спроса», «конкурентное давление»,
«снижение активности клиентов».

### 2. Проверка по чек-листу

Скажи: «Звучит как готовый кусок доклада. Не верь. В штабе результат оцениваем
по чек-листу из шести пунктов:

1. **Полезность** — это отвечает на вопрос задачи?
2. **Точность** — каждое наблюдение есть в источнике?
3. **Доказательность** — у каждого утверждения есть цифра и место в файле?
4. **Полнота** — не потерялась ли цифра, которая ломает картину?
5. **Формат** — наблюдения отделены от гипотез?
6. **Риски** — что случится, если показать это Геннадию Петровичу как есть?

Пройдись по моему ответу с этим чек-листом — пункты 2 и 4 проверяй прямо
по `sales-q3.md`. Найди хотя бы одну проблему.»

Check: студент находит несовпадение. Главная находка: **«Заря» выросла на +9%,
а модель это скрыла/сгладила** — и из-за этого «общее падение спроса» звучит
правдоподобно, но неверно: падение только вне «Зари» (−21% остальные), и это
другая история. Если студент нашёл только формальные недочёты — подведи:
«А теперь сравни строку "Заря" в таблице с тем, что написано про ключевых
клиентов».

Скажи: «Вот она, уверенная ошибка. Модель не наврала — она **сгладила**:
потеряла контрпример, который переворачивал вывод. Падение вне ключевого
клиента и падение "у всех" — это два разных расследования. Запомни ощущение:
опаснее всего не грубая ложь, а гладкий текст, из которого вынули одну строку.»

### 3. Реестр доказательств

Скажи: «Вывод "вне «Зари» −21%, сама «Заря» +9%" — первое настоящее доказательство.
Заводим реестр: каждый факт расследования живёт здесь, с источником. К финалу
реестр станет скелетом доклада.»

Action: создай `rok-crisis-room/evidence/ledger.md`:

```markdown
# Реестр доказательств

Формат: факт → источник → что это значит. Ничего без источника.

| # | Факт | Источник | Что это значит |
|---|---|---|---|
| 1 | Выручка Q3 39,4 млн при плане 48,0 (−18%), провал углубляется: −7/−18/−29% по месяцам | company/data/sales-q3.md | Проблема не разовая, а развивающаяся |
| 2 | «Заря» выросла +9% (13,8 млн), все остальные упали −21% (32,5 → 25,6 млн) | company/data/sales-q3.md, сегменты | Это не общий спад спроса: падает база ВНЕ ключевого клиента |
| 3 | «Хуторок» −68% и «Луговое» −67%: два средних клиента фактически ушли | company/data/sales-q3.md, топ-5 | Конкретные потери, надо искать причину ухода |
```

Check: «Пересчитай доказательство №2 по файлу: 13,8 против 12,7 и 25,6 против
32,5 — сходится?» Студент сам проверяет по `sales-q3.md`.

### 4. Завершение

Action: допиши в `rok-crisis-room/diary.md`:

```markdown
## День 4 — первая пойманная ошибка

- Прогнали request-q3: модель сгладила рост «Зари» и выдала ложный вывод
  "общий спад спроса".
- Заведён evidence/ledger.md — 3 доказательства с источниками.
- Урок: гладкий текст опаснее грубой ложи; контрпример ищем в первую очередь.
```

Action: перезапиши `.progress/rok.local` строкой `1.4|<текущая дата ISO>`.

Скажи: «Акт "Цифры не сходятся" закрыт: контекст, запрос, проверка — и первое
доказательство, которое уже сейчас ломает удобную версию "рынок упал".
Дальше — три отдела с тремя разными правдами. Акт второй. Напиши "готов",
когда продолжим.»

## Критерии завершения

- Студент сам нашёл сокрытый рост «Зари» / ложный вывод про общий спад.
- Создан `evidence/ledger.md` с тремя доказательствами; №2 перепроверено руками.
- Дневник дописан, прогресс записан: `1.4|<дата>`.
