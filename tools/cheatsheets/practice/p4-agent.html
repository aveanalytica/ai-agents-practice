Что такое агент

Чат отвечает — агент делает. Агент сам проходит цикл доводки в твоих системах
Модуль 4 · Работа с агентом определение
🤖 Определение
Агент — это ИИ, который сам выполняет задачу: планирует шаги, действует через инструменты, смотрит на результат и доводит его — а не просто отвечает на один вопрос.
01 Из чего состоит агент три части, убери любую — агента нет
🧠 Модель
То же ядро, что в чате
🔌 Инструменты
Доступ к твоим системам через MCP (Модуль 3)
🔁 Авто-цикл
Сам крутит цикл доводки до результата
02 Автономный цикл — агент крутит его сам тот же цикл доводки из Модуля 3, но без твоих рук
1 · Плансам разбивает задачу на шаги
2 · Действиеидёт в систему через инструменты — читает, собирает
3 · Наблюдениесмотрит на результат: чего не хватает по критерию
4 · Правкаделает ещё проход — сам, без тебя
🔁 Снова↑ и снова — пока не сойдётся по критерию готовности
03 Чат или агент — как выбрать задачу не тащи агента туда, где хватает чата
💬 Чат
  • один вопрос → один ответ
  • материал уже под рукой
  • цикл крутишь ты сам
  • коротко и быстро
🤖 Агент
  • нужно несколько шагов
  • данные живут в системе
  • цикл крутит он сам
  • длинная задача с доступом к инструментам
