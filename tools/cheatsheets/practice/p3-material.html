Модуль 3 · Путь к рабочему результату первоисточник MCP
01 Первоисточник, а не пересказ каждый пересказ теряет смысл
✗ Пересказ
Сам ужал тред в три фразы → модель пересказывает твой пересказ. Смысл потерян дважды.
✓ Первоисточник
Дай модели сам тред / документ / данные. Она работает с фактами, а не с твоей выжимкой.
02 Когда копипаст не тянет — MCP живую систему в чат не вставишь
🔑 MCP — ключ от рабочего инструмента
MCP — это способ подключить твой рабочий инструмент напрямую к ИИ, чтобы он сам брал оттуда актуальные данные без копипаста. Грубо: ты даёшь ИИ ключ к рабочему инструменту, и он сам заходит и читает нужное. Живую систему (доску задач, базу знаний) в чат не вставишь — а через MCP ИИ читает её сам.
03 Чем работать — чат или агент короткая задача → чат, длинная → агент
💬 Чат с модельюкороткий цикл на 1–2 прохода. Текст под рукой — даёшь копипастом. Не усложняй
🤖 Агент (opencode)длинная многопроходная задача. Через MCP подключаешь рабочие инструменты — ИИ берёт данные сам
