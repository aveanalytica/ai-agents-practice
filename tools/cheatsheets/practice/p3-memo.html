02 Четыре приёма модуля каждый приём — из своего занятия
1 · Один проход — это черновикпервый ответ ≈80%, а не финал. Большую задачу бей на проходы, не бери одним промптом
2 · Точечная правка, не «перепиши»что сохранить · что заменить · каким стать. Дефект из проверки (М2) = готовая правка
3 · Дай первоисточник, а не пересказне двигается за 2–3 прохода — меняй не слова, а материал. Живую систему — через MCP
4 · Стоп по критерию готовностиостанавливаешься, когда результат соответствует критерию (М1), а не «когда надоело»
03 Инструменты · границы данных общие правила безопасной работы с ИИ
💬 Чат с модельюкороткий цикл на 1–2 прохода, текст под рукой — копипастом
🤖 opencodeагент для длинных задач + MCP для доступа к рабочим инструментам
🟢 Публичные данныесвободно
🔵 Внутренниетолько через корпоративный контур ИИ
🔴 Персональные / секретынельзя: ФИО, email, телефоны, ключи, токены, внутренние URL/IP
🔁 Полезный результат не пишется одним запросом — он доводится
Агент — это автоматизированный цикл. Критерий «готово» остаётся за тобой.
