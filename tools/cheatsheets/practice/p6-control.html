Контроль на масштабе

Много рук — не повод ослабить контроль, а повод усилить. Правила из М4, умноженные на число агентов.
Модуль 3 · Масштаб: ассистент и команда агентов занятие 3.8 read-only по умолчанию
01 Три правила — на масштабе важнее агентов много — контроль усиливаем, а не ослабляем
🔑 Минимум прав — по умолчанию только чтение Команде из десяти агентов — тем более. Читать и готовить можно, право менять — точечно и только где реально нужно.
🛑 Точка контроля — на необратимом Не следи за каждым шагом каждого агента. Одна ясная точка «стоп» перед отправкой / публикацией / изменением в боевой системе: команда собрала черновик — ты говоришь «ок».
🔒 Граница данных Чем больше агентов и источников, тем легче утащить лишнее. Что нельзя выносить из рабочего контура — не выносишь. Правила — в общих правилах безопасной работы с ИИ; сомневаешься — спроси куратора курса в учебном кабинете AVE Analytica.
02 Что когда применять выбор формы — по форме задачи
Один запрос / агент одиночная задача; шаги зависят друг от друга (М4)
Клоны пачка однотипных независимых кусков разом (6.1)
Специалисты + оркестрация большая разнородная задача → синтез (6.2)
Сабагент роль нужна постоянно — завёл раз, вызываешь снова (6.3)
🎯 Главное
Ты не микроменеджишь каждого агента — ты держишь границы и одну точку «стоп» на результате. Много исполнителей, одна точка контроля на необратимом.
