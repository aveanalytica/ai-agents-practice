Что такое MCP

MCP — это руки агента в твоих рабочих системах: стандарт подключения инструментов к ИИ
Модуль 4 · Работа с агентом opencode безопасность
🔌 Определение
MCP (Model Context Protocol) — открытый стандарт подключения внешних систем и инструментов к ИИ-агенту. MCP-сервер — это «переходник», через который агент сам читает и делает что-то в твоих рабочих системах: файлах, базах данных, трекерах задач, вебе. Без MCP агент — умный собеседник в пустой комнате; с MCP — он в твоём рабочем контуре.
01 Зачем нужен конец эпохи копипаста
Без MCPты вручную копируешь данные в чат, а результат — обратно в систему
С MCPагент сам заходит в систему, берёт актуальное и возвращает результат
Ключевая выгодаживую систему (доску задач, базу знаний) в чат не вставишь — через MCP агент читает её сам
02 Примеры типовых MCP-серверов один сервер = одна система
📁 Файловая системачитать и искать файлы проекта, просматривать папки
🗄 База данныхзапросы к БД; по умолчанию — только чтение (SELECT)
🔎 Веб-поискактуальная информация из интернета вместо устаревших знаний модели
📋 Трекер задач / база знанийчитать задачи, документацию, заметки команды
03 Как подключается в opencode — концепция точный синтаксис — сверяйся с документацией opencode
Шаг 1 · КонфигMCP-сервер описывается в конфиге opencode: имя сервера, команда запуска (локальный) или URL (удалённый), нужные переменные окружения
Шаг 2 · Перезапускпосле правки конфига перезапусти opencode — без перезапуска новый сервер не подхватится
Шаг 3 · Проверкаубедись, что сервер появился в списке доступных инструментов и отвечает на простой запрос
⚠ Не выдумывай флаги
Синтаксис конфигурации MCP в opencode меняется между версиями. Точные поля и команды бери из официальной документации opencode и --help, а не из памяти или старых заметок.
04 Типичные ошибки сначала проверь это, потом ищи глубже
Агент не видит серверзабыл перезапустить opencode после добавления сервера в конфиг
Сервер не стартуетпроверь команду запуска вручную в терминале — увидишь настоящую ошибку
Ошибка авторизациитокен/ключ не подхватился — проверь переменные окружения и их имена в конфиге
Агент «не может»у сервера нет нужного права (например, read-only) — это часто намеренно, см. правила ниже
✓ Правила безопасности
  • Минимум прав: подключай только нужные серверы и инструменты, не «всё на всякий случай»
  • Только чтение по умолчанию: запись и действия включай осознанно и под контролем (см. «Контроль агента»)
  • Секреты — в переменных окружения, не в чате и не в коде: токены, ключи, внутренние URL/IP
  • Границы данных: внутреннее — через корпоративный контур, персональные данные не отправляем
  • Сомневаешься, можно ли пускать агента в систему или давать право на запись, — спроси куратора курса в учебном кабинете AVE Analytica
