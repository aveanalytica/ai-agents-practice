Контроль агента

Человек в контуре: доверие настраивается по риску действия, а не на каждом шаге
Модуль 2 · Путь к результату с агентом главное правило
01 Обратимое vs необратимое главный вопрос: можно ли откатить?
✅ Обратимое — доверяй
  • читать, искать, собирать
  • делать черновик
  • сводить и анализировать
🛑 Необратимое — точка контроля
  • отправить письмо / разослать пользователям стриминга «Волна»
  • изменить, закрыть, удалить
  • запостить, выдать доступ, оплатить
02 Глубина контроля по риску классификатор из Модуля 2
🟢 Читать · собирать · черновикобратимо. Доверяй, не тормози
🟡 Мелкое действиепусть делает, но покажи результат
🔴 Необратимое / заметноеточка контроля: покажи черновик, жди «ок»
⚫ Опасное и необратимоесам не делает — или только под твоим присмотром
03 Два правила безопасной работы с ИИ общие правила из практикума
🔑 Минимум прав
Дай только нужный доступ. По умолчанию — только чтение. Нет прав на отправку → не отправит даже по ошибке.
🛡 Граница данных
Внутреннее — через корпоративный контур. ПДн, ключи, секреты — минимизируй. Сомнение → куратор курса в учебном кабинете AVE Analytica.
🎛 Главное правило
Обратимое — доверяй, необратимое — точка контроля. Минимум прав убирает опасность, точки контроля ловят остальное.
